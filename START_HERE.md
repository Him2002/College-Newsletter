# 🎓 START HERE

Welcome to the **Dayananda Sagar Institutions - College Newsletter & Event Management System**

This is your complete, production-ready MERN application. Everything is ready to go!

## ⚡ Quick Start (5 Minutes)

**Terminal 1 - Backend:**
```bash
cd backend
npm install
npm run dev
```

**Terminal 2 - Frontend:**
```bash
cd frontend
npm install
npm run dev
```

**Browser:**
Open `http://localhost:3000`
